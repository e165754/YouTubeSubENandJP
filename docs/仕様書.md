## 1. プロダクト概要

### 1.1 目的

公開されている YouTube 動画を、**英語学習用のビュワー**として使う。ブラウザ内で次を一気通貫で行う。

- キーワード検索で動画を探す  
- 公式 IFrame プレイヤーで再生する  
- **英語・日本語の字幕**をオーバーレイ・全文リストで見る  
- 英語字幕の**単語をクリック**し、LLM で意味・文脈などを表示する  

本アプリは YouTube の代替クライアントではなく、**学習補助**を目的とする。

### 1.2 技術スタック（一覧）

| 区分 | 内容 |
|------|------|
| フレームワーク | Next.js 16（App Router） |
| 言語 | TypeScript |
| スタイル | Tailwind CSS 4 |
| サーバー処理 | Route Handlers（`src/app/api/**/route.ts`） |
| ブラウザ API | YouTube IFrame Player API（再生位置の取得・シーク） |

### 1.3 外部サービス（依存関係）

| サービス | 用途 | 必須か |
|----------|------|--------|
| YouTube Data API v3 | 検索（`search.list` + `videos.list`） | **必須**（`YOUTUBE_DATA_API_KEY`） |
| YouTube 本体 | IFrame 再生、字幕 XML（InnerTube / 視聴ページ HTML / timedtext） | **必須**（動画視聴・字幕取得） |
| OpenAI 互換 Chat Completions | 単語クリック時の解析 | 推奨（未設定だと解析だけ失敗） |
| Hugging Face Hub（モデル配布） | `@xenova/transformers` が初回に NLLB モデルを取得する | 字幕補完を使う場合は接続が必要（**翻訳 API キーは不要**） |

**重要（公式 Captions API について）**  
YouTube Data API の `captions.list` / `captions.download` は、**API キーだけでは利用できない**（OAuth と動画オーナー権限が必要）。本プロジェクトは**字幕本文を timedtext・InnerTube 等から取得**する方針であり、Captions API には依存しない。  
参考: [Captions: list](https://developers.google.com/youtube/v3/docs/captions/list)

## 2. ユーザーができること（機能一覧）

### 2.1 検索ページ（`/`）

- 検索語入力（**初期値は `"TED"`**）  
- 結果タイプ: 動画 / チャンネル / プレイリスト  
- 並び順: 関連度 / 日付 / 評価 / 再生回数  
- 投稿日プリセット: 指定なし / 7日 / 30日 / 365日以内  
- 動画の長さ: 指定なし / 短い / 中くらい / 長い  
- 一覧から動画を選ぶと `/watch/[videoId]` へ遷移  
- **さらに読み込む**（`nextPageToken` によるページング）  

### 2.2 視聴ページ（`/watch/[youtubeVideoId]`）

- IFrame で再生  
- 字幕オーバーレイ（英語のみ / 日本語のみ / 両方）  
- 「学習用に日本語を弱表示（ホバーで確認）」オプション  
- 右ペイン:**全文スクリプト**（行クリックでその位置へシーク）  
- 英語行内の**単語クリック** → 下部パネルに LLM 解析結果  
- 日本語の取得元に応じた**注記バナー**（YouTube 自動翻訳 / 機械翻訳フォールバック）

## 4. 自前 API（Route Handlers）

クライアントは **必ずこれらの相対パス**経由で外部キーを隠して呼ぶ。

### 4.1 `GET /api/youtube/search`

**役割:** YouTube Data API で検索し、一覧用 JSON を返す。

**クエリパラメータ（主要）**

| パラメータ | 説明 | 既定・備考 |
|------------|------|------------|
| `q` | 検索語 | 2 文字未満は 400 |
| `type` | `video` / `channel` / `playlist` | 既定 `video` |
| `order` | `relevance` / `date` / `rating` / `viewCount` | 既定 `relevance` |
| `publishedAfter` | RFC3339 日時 | 省略可 |
| `videoDuration` | `any` / `short` / `medium` / `long` | 動画タイプ時のみ意味あり |
| `pageToken` | 次ページトークン | 省略可 |
| `maxResults` | 1〜25 | 既定 12 |

**成功時 JSON（概要）**

- `videoItemList`: `YouTubeSearchResultVideoItem[]`  
- `nextPageToken`: `string | null`  
- `totalResultEstimate`: `number | null`  

**失敗時:** `errorMessage` を含む JSON。キー未設定は 500。

---

### 4.2 `GET /api/captions?videoId=...`

**役割:** 指定動画の字幕を取得し、**英語・日本語を時間軸で対応付けた** `bilingualCueList` を返す。

**クエリ**

- `videoId`（必須・短すぎると 400）

**成功時 JSON（フィールド）**

| フィールド | 型のイメージ | 意味 |
|------------|--------------|------|
| `bilingualCueList` | `BilingualTranscriptCue[]` | 1 行ごとの英日ペア（時刻は英語基準） |
| `resolvedEnglishLanguageCode` | `string \| null` | 採用した英語トラックの言語コード |
| `resolvedJapaneseLanguageCode` | `string \| null` | 採用した日本語トラックの言語コード（機械翻訳のみで埋めた場合は `"ja"` になり得る） |
| `japaneseIsYoutubeAutoTranslation` | `boolean` | 日本語が YouTube の `tlang` 系の自動翻訳 URL で取ったものか |
| `japaneseIsMachineTranslationFallback` | `boolean` | 欠損行を機械翻訳で 1 行以上補ったか |
| `japaneseMachineTranslationProvider` | `null` / `"local_nllb"` | 実際に補完に使ったプロバイダ（未補完時は `null`） |

**ローカル字幕翻訳:** [ローカル字幕翻訳_NLLB.md](./ローカル字幕翻訳_NLLB.md)

**失敗時:** 英日とも本文が取れない場合 404 + `errorMessage`。

**字幕取得の考え方（高レベル）**

1. **InnerTube** `player`（ANDROID クライアント）で `captionTracks` を取得し、`baseUrl` から XML（`fmt=srv3`）を取る  
2. ダメなら **視聴ページ HTML** の `ytInitialPlayerResponse`（字幕トラック数が最大のブロックを採用）  
3. まだ足りなければ **`/api/timedtext` 直叩き**（言語コードのフォールバック）  
4. 日本語ネイティブを **自動翻訳より優先**してマージ  
5. 日本語が無い場合は英語 `baseUrl` に **`tlang=ja`** を付けて再取得を試す  
6. パース後に英日をマージ（`buildBilingualTranscriptCueListFromSeparateTracks`）  
7. `DISABLE_LOCAL_NLLB_SUBTITLE_TRANSLATION` で無効化されていなければ、**欠損行だけ**ローカル NLLB（`@xenova/transformers`）で英→日を埋める。ただし **YouTube から日本語が 1 行も取れない**（`tlang=ja` 含むすべて失敗）場合は、全文が欠損扱いになり逐次翻訳で `/api/captions` がタイムアウトしやすいため、**既定では NLLB をスキップ**し英語字幕のみ返す。全文をローカル翻訳したいときだけ `ENABLE_LOCAL_NLLB_FOR_ENGLISH_ONLY_TRANSCRIPTS` を有効にする。  

---

### 4.3 `POST /api/llm/word-analysis`

**役割:** クリックされた語とその文（英語）を LLM に渡し、学習向けの説明 JSON を返す。

**リクエスト JSON**

| フィールド | 必須 | 内容 |
|------------|------|------|
| `headword` | はい | 調べる語・表現 |
| `surroundingSentenceEnglish` | いいえ | 文脈（推奨） |

**成功時:** `WordAnalysisResult` 型に沿った JSON。

**失敗時:** 400（入力不正）/ 502（LLM 失敗）+ `errorMessage`。

## 6. 環境変数

テンプレート: リポジトリ直下の `.env.example`（**秘密はコミットしない**。本番はホスティングのダッシュボードに設定）。

| 変数 | 必須 | 用途 |
|------|------|------|
| `YOUTUBE_DATA_API_KEY` | **はい**（検索のため） | Data API v3 |
| `OPENAI_COMPATIBLE_API_KEY` または `OPENAI_API_KEY` | 推奨 | 単語解析 |
| `OPENAI_COMPATIBLE_BASE_URL` | 任意 | 既定 `https://api.openai.com/v1` |
| `OPENAI_COMPATIBLE_MODEL` | 任意 | 例: `gpt-4o-mini` |
| `DISABLE_LOCAL_NLLB_SUBTITLE_TRANSLATION` | 任意 | `true` / `1` のときローカル NLLB による欠損補完を**行わない**（サーバーレス本番でタイムアウトを避ける等） |
| `ENABLE_LOCAL_NLLB_FOR_ENGLISH_ONLY_TRANSCRIPTS` | 任意 | `true` / `1` のとき、**日本語トラックが 0 行**の動画でもローカル NLLB で全文を翻訳しようとする（長尺ではタイムアウトしうる。既定はオフで英語のみ即返却） |
| `DISABLE_ONNX_CLEAN_UNUSED_INITIALIZER_STDERR_FILTER` | 任意 | `true` / `1` のとき `next dev` での ONNX `CleanUnusedInitializers...` 行の stderr 間引きを**無効化** |
| `DEBUG_YOUTUBE_CAPTION_PIPELINE` | 任意 | `true` / `1` のときサーバーに `[caption-pipeline][server]` ログ（字幕 API の段階的診断） |
| `NEXT_PUBLIC_DEBUG_YOUTUBE_CAPTION_PIPELINE` | 任意 | `true` / `1` のときブラウザ Console に `[caption-pipeline][client]` ログ（`next dev` 再起動後に反映） |
| `NEXT_PUBLIC_SUBTITLE_PLAYBACK_SYNC_LAG_SECONDS` | 任意 | 字幕行の判定で `getCurrentTime` から差し引く秒（-5〜5）。**正**は実効時刻が遅れ**字幕が遅れる**。**負**は実効時刻が進み**字幕が早く切り替わる**。**未設定時は -0.35** |

## 10. 品質・利用上の注意

- **字幕の取得可否**は動画・地域・YouTube 側仕様に依存し、保証されない。  
- **英日の対応付け**はヒューリスティック（重なり・境界ギャップ・中点距離フォールバック）。ズレや誤対応が残りうる。  
- **YouTube / Google の利用規約・ロボット規約**に従うこと。サーバーからの大量自動取得はリスクがある。  
- **LLM の説明**は誤りがありうる。学習の最終判断は人間が行う。  
- **ローカル字幕翻訳**は CPU・メモリ・初回ダウンロード・応答時間に注意（長い動画では `/api/captions` が非常に遅くなりうる）。
