# オンラインデプロイ手順（本プロジェクト）

Next.js App Router ＋ Route Handlers のため、**Node ランタイム**で動くホスティングが必要です。公式との相性が良い **Vercel** を推奨します。

## 前提

- リポジトリを **GitHub / GitLab / Bitbucket** などに push できること（Vercel が Git 連携する場合）
- または Vercel CLI でログインして直接デプロイできること

## 推奨: Vercel（Git 連携）

1. [Vercel](https://vercel.com) にサインアップし、Git プロバイダと連携する。
2. **Add New Project** → 本リポジトリを選択して **Import**。
3. **Framework Preset**: Next.js（自動検出のまま）。
4. **Build Command**: `npm run build`（既定）  
   **Output**: 既定（変更しない）。
5. **Environment Variables** に、本番用の値を設定する（下表）。`.env.local` はアップロードしない。Vercel のダッシュボードにだけ入力する。
6. **Deploy** を実行する。

### 本番で設定する環境変数

| 変数 | 必須 | 用途 |
|------|------|------|
| `YOUTUBE_DATA_API_KEY` | **必須** | 検索 API |
| `OPENAI_COMPATIBLE_API_KEY` または `OPENAI_API_KEY` | 推奨 | 単語解析（未設定だと解析 API が失敗） |
| `OPENAI_COMPATIBLE_BASE_URL` | 任意 | 既定 `https://api.openai.com/v1` |
| `OPENAI_COMPATIBLE_MODEL` | 任意 | 例: `gpt-4o-mini` |
| `DISABLE_LOCAL_NLLB_SUBTITLE_TRANSLATION` | 任意 | `1` または `true` で、欠損日本語の**ローカル NLLB 補完を無効化**（Vercel 等でタイムアウト・メモリ不足を避ける） |
| `ENABLE_LOCAL_NLLB_FOR_ENGLISH_ONLY_TRANSCRIPTS` | 任意 | `1` または `true` で、**日本語トラック 0 行**の動画でも全文をローカル NLLB する（長尺ではタイムアウトしうる。**既定はオフ**で英語のみ返す） |

**注意:** 字幕取得はサーバーから YouTube（InnerTube / timedtext 等）へアクセスします。Vercel のサーバーレスは利用規約・レート制限の対象になり得るため、運用ポリシーは各自で確認してください。

**ローカル NLLB:** 日本語が少なくとも 1 行取れた動画では、欠損行をサーバー上の ONNX モデルで補います（[ローカル字幕翻訳_NLLB.md](./ローカル字幕翻訳_NLLB.md)）。**日本語が完全に無い動画では既定で NLLB を走らせず**英語字幕だけ返します。サーバーレス本番では無効化を推奨することが多いです。

### YouTube Data API キー（本番）

- [Google Cloud Console](https://console.cloud.google.com/) でプロジェクトを作成し **YouTube Data API v3** を有効化する。
- API キーを発行し、**HTTP リファラー（ウェブサイト）** などでキー制限する場合、Vercel のドメイン（`https://あなたのプロジェクト.vercel.app/*`）を許可リストに含める必要がある場合があります。サーバー側のみでキーを使う構成では **IP 制限ではなくキー制限の扱い**に注意する（Vercel の出口 IP は固定しにくい）。

## CLI でデプロイ（代替）

ローカルから直接上げる例:

```bash
npm i -g vercel
cd /path/to/yt
vercel login
vercel        # 初回はプロジェクト紐付けの対話
vercel --prod # 本番 URL
```

環境変数は `vercel env pull` / ダッシュボードで同期する。

## その他のホスティング

- **Netlify**（Next の SSR 対応プラン）
- **自前 VPS** 上で `npm run build` → `npm run start`（Node 常駐）
- **Docker** + `next start` または `output: 'standalone'`（必要なら別途設定）

本リポジトリでは既定の `next build` のみでよい。

## デプロイ後の確認

- トップ `/` が開く
- 検索が動く（`YOUTUBE_DATA_API_KEY`）
- 任意の動画で `/watch/[id]` が開き、字幕 API が応答する（動画・地域により失敗しうる）
